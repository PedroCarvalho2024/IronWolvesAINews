AI digest for 2026-10-23 — 6 items

> **Today's big item:** Anthropic has handed Agent Skills to the Agentic AI Foundation, the Linux Foundation group that already runs MCP. A skill is a folder with a SKILL.md file and optional scripts, and more than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot and VS Code, already support the format. Engineers from Anthropic, Google, OpenAI and others will now maintain it as a vendor-neutral standard, so skills you write today should keep working across tools.

## New model launches

- **Recursive releases Flint, an open-weights coding model for laptops**
  A 40B MoE (mixture of experts, only part of the model runs per token) model with about 2.5B active parameters, Apache 2.0 weights and a claimed 125+ tokens per second on an M4 Pro MacBook, so you can try a local coding agent without a cloud bill.
  https://recursive.com/updates/introducing-recursive-flint

## RAG / vector DB tooling

- **Plain RAG beats fancy agent memory in a new study**
  Simple retrieval and reranking over the raw chat history (Raw-RAG) came first in six of seven benchmark setups against complex agent memory systems, so try the simple baseline before you build a memory layer.
  https://arxiv.org/abs/2610.30755

## Agent orchestration frameworks

- **Agent Skills moves to the Linux Foundation**
  The spec, GitHub org and agentskills.io domain now belong to the Agentic AI Foundation, which plans versioned releases, a formal proposal process and security guidance for people who install skills.
  https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation

- **Walmart opens an MCP server for AI shopping agents**
  Agent Gateway is an invite-only beta MCP (Model Context Protocol, a standard way to give agents tools) server that lets approved agents search and buy at Walmart and Sam's Club, with per-agent spending limits set by the customer.
  https://techcrunch.com/2026/10/21/while-amazon-blocks-ai-agents-walmart-rolls-out-the-welcome-mat/

## Cloud AI service updates

- **Claude API now available inside Google Cloud, run by Anthropic**
  You can call the full Claude Platform with Google Cloud IAM and pay on your Google Cloud bill, and unlike the Google-run option you get new features and betas on the same day they ship.
  https://claude.com/resources/articles/claude-models-on-google-cloud-anthropic-managed

- **Bedrock AgentCore Gateway adds automatic model fallback**
  The gateway now accepts the standard Bedrock InvokeModel APIs and can retry a request on a backup model or provider when the main one is throttled or down, so your app still sends one request and gets one answer.
  https://aws.amazon.com/about-aws/whats-new/2026/10/agentcore-gateway-invokemodel-fallback/
