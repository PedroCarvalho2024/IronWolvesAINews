AI digest for 2026-10-22 — 8 items

> **Today's big item:** Anthropic released API version `2026-10-21`, its first new API version since `2023-06-01`, plus new major SDK versions (Python 2.0.0, TypeScript 1.0.0, Go 2.0.0 and others) that use it by default. On the new version, a request that sends `temperature`, `top_p` or `top_k` fails with a 400 error, and the new SDKs also remove the old Text Completions API and send your key as `Authorization: Bearer`. Pin your current SDK version and read the migration guide before you upgrade.

## New techniques / papers

- **Agents that manage their own KV cache run cheaper**
  Instead of summarising old context, the agent drops stale tool outputs straight from the KV cache (the model's saved memory of past tokens), which scored 1.7 points higher and cost 27.7% less than summarisation, and the AKV serving engine is open source.
  https://arxiv.org/abs/2610.28577

## RAG / vector DB tooling

- **RAG (feeding docs to an LLM) tricks do not simply add up**
  Across 450 pipeline setups, three retrieval techniques expected to give +47% together gave only +17%, so test any new RAG trick inside your full pipeline, using the open-source LASAGNA framework if you like.
  https://arxiv.org/abs/2610.29722

## Agent orchestration frameworks

- **Amazon WorkSpaces opens cloud desktops to AI agents over MCP**
  A managed MCP (Model Context Protocol, a standard way to give agents tools) service lets any MCP client open a WorkSpaces desktop, launch apps and stream a live view, under the same network rules as human users.
  https://aws.amazon.com/about-aws/whats-new/2026/10/workspaces-ai-agents-oauth-connection-management

## Cloud AI service updates

- **Anthropic ships API version 2026-10-21 and new major SDKs**
  The new SDKs bring breaking changes (sampling parameters rejected, Text Completions removed, new auth header) and move from the MIT to the Apache 2.0 license, so plan the upgrade instead of letting it happen by accident.
  https://platform.claude.com/docs/en/api/migration-2026-10-21

- **Claude API adds user profiles for per-customer safety actions**
  If you serve many end customers through one Anthropic account, you can now tag each request with an `anthropic-user-profile-id` header so a ban or restriction hits only that customer instead of your whole organisation.
  https://platform.claude.com/docs/en/manage-claude/user-profiles

- **Reflection's open-weight Beam model lands on SageMaker JumpStart**
  The Apache-2.0 Beam model can now be fine-tuned and deployed from SageMaker JumpStart in two US regions, with BF16, FP8 and NVFP4 checkpoints (quantised versions that use less memory).
  https://aws.amazon.com/about-aws/whats-new/2026/01/reflection-beam-on-sagemaker-jumpstart-and-aws-trainium/

## AI security & compliance

- **Claude admins can now switch off or fence in web fetch**
  Admins can disable the web fetch tool or limit it to allowed domains, and Managed Agents now obey these limits even after redirects, which shrinks the damage a prompt injection (hidden instructions in content) can do by sending data out.
  https://platform.claude.com/docs/en/release-notes/api
