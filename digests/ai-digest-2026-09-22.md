## New techniques / papers

- **Google shows how to stop self-improving agents from overfitting**
  Agents that rewrite their own prompts and tools tend to memorise the test set, and RRSI adds limits that keep the gains on unseen tasks while using 30% fewer tokens.
  https://arxiv.org/abs/2609.24972

- **Yellow.ai publishes a cheaper document ingestion pipeline for RAG**
  D-RAC converts any office format to PDF first, then chunks it (splitting docs into pieces for retrieval), cutting chunking cost by ~78% versus asking a frontier model to do it.
  https://arxiv.org/abs/2609.24220

- **Paper argues search results should be built for the model, not the human**
  It ranks retrieved documents by whether they actually support an answer and how trustworthy they are, instead of by classic relevance score.
  https://arxiv.org/abs/2609.23354
