## New techniques / papers

- **WikiTrace: agent memory that keeps the receipts**
  Each lesson an agent saves links back to the full log of the run it came from, so the agent can check a doubtful lesson before acting, and it beat other memory methods on five agent benchmarks.
  https://arxiv.org/abs/2611.14320

- **DeepMind's AlphaProof Code formally verifies Signal's protocol code**
  Agents running on Gemini Carbon wrote over six million lines of Lean proofs (machine-checked maths about code) in about four weeks, with humans reviewing only about 1% of it.
  https://deepmind.google/blog/introducing-alphaproof-code/

## Interesting GitHub repos

- **agent-browser 0.42.0 adds "saved flows"**
  Vercel's browser tool for AI agents can now record a web task once and replay it as plain HTTP requests, which is faster and cheaper than having the agent click through the page again.
  https://github.com/vercel-labs/agent-browser/releases/tag/v0.42.0

- **llama.cpp merges FP8 KV-cache support**
  The KV cache (the model's working memory of the conversation) can now be stored in 8-bit numbers instead of 16-bit, so self-hosted models fit longer contexts in the same GPU memory.
  https://github.com/ggml-org/llama.cpp/pull/28392

## Ontologies & knowledge graphs for AI

- **OGDA: data agents that first build an ontology of your data lake**
  An ontology (a map of the concepts in your data and how they relate) is built and checked by agents up front, so the analysis agent does not burn its context window searching through hundreds of tables, gaining up to 10.8 points on KramaBench and DiscoveryBench.
  https://arxiv.org/abs/2611.12114

## RAG / vector DB tooling

- **OpticalRAG compresses retrieved pages into 16 tokens using images**
  This RAG (feeding docs to an LLM) method renders documents as page images and squeezes them into a handful of tokens, which cuts prompt cost while scoring best among compression methods on three long-document benchmarks.
  https://arxiv.org/abs/2611.13675

- **When retrieved text is too vague, LLMs guess instead of saying "I don't know"**
  If a passage only names a broad category (for example "hyperlipidemia" when the question needs the exact subtype), models answer anyway and are wrong about half the time, and the authors show an ontology lookup helps recover the exact answer.
  https://arxiv.org/abs/2611.14355

## AI security & compliance

- **Microsoft shows agents can be backdoored by editing fewer than 10 neurons**
  The "Lazarus" attack hides a trigger in a model's weights without retraining, passes normal safety tests, and could make an agent run attacker code later, so only use model weights from sources you trust and limit what your agents can run.
  https://www.microsoft.com/en-us/research/blog/lazare-veni-foras-reprogramming-dormant-neurons-to-backdoor-ai-agents/

- **Agent swarms break models that look safe on prompt-injection benchmarks**
  An automated attacker built from several agents reliably made models follow instructions hidden in tool output, even models that scored well on public tests like GraySwan Arena.
  https://arxiv.org/abs/2611.11861

- **Embedding tricks for RAG access control do not keep documents secret**
  Methods that transform vectors so each user only retrieves allowed documents do keep users apart, but a user with a few hundred sample pairs can recover the original embeddings, so do not rely on them for confidentiality.
  https://arxiv.org/abs/2611.14061
