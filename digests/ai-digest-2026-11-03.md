AI digest for 2026-11-03 — 13 items

> **Today's big item:** Google has removed Gemini 2.5 Pro and Gemini 2.5 Flash from AI Studio, and from December 1 any API call to them will be quietly sent to a newer model and billed at that model's price. Calls to `gemini-2.5-pro` will go to `gemini-3.8-flash`, and calls to `gemini-2.5-flash` will go to `gemini-3.5-flash-lite`. The newer models change how function calling, thinking settings and some sampling options work, so update your model names and test before December 1.

## New techniques / papers

- **CrossSWE: coding agents struggle when a change spans several repos**
  A new benchmark of 171 real tasks that need coordinated changes across repositories shows the best model passing only 58.48%, with mismatched changes between repos as the most common failure.
  https://arxiv.org/abs/2611.01484

- **What goes into AGENTS.md and CLAUDE.md files, measured**
  A study of 3,387 agent instruction files from 1,000 GitHub repos found that 16.1% of matching sections across formats give conflicting advice, and it proposes a template that raised section coverage from 18.7% to 82.8%.
  https://arxiv.org/abs/2611.02383

## Interesting GitHub repos

- **Vercel agent-desktop: let an agent use desktop apps without screenshots**
  An Apache-2.0 CLI for macOS, Windows and Linux that reads apps through the OS accessibility tree and returns JSON with an ID for each button or field, so your agent clicks by ID instead of by pixel position.
  https://github.com/vercel-labs/agent-desktop

## Ontologies & knowledge graphs for AI

- **Smaller knowledge-graph context, same answers**
  Using known relation paths to pick only the KG (knowledge graph) facts that can actually derive an answer, seven open LLMs matched a strong graph-RAG baseline on ComplexWebQuestions with a quarter of the prompt tokens.
  https://arxiv.org/abs/2611.01733

## RAG / vector DB tooling

- **EviCast: predict whether retrieval will help before you deploy it**
  It tests your model once against controlled sets of evidence and then estimates the gain of each candidate retriever, picking correctly in all 14 HotpotQA setups with 80% fewer test calls, and the code is public.
  https://arxiv.org/abs/2611.02387

- **HVMap: search several vector databases built with different embedding models**
  Instead of re-embedding everything into one space, it learns a small mapping between embedding spaces (the number formats each model gives text), reporting up to 3.59x better ranking quality than baselines.
  https://arxiv.org/abs/2611.01514

## AI security & compliance

- **Most MCP setups never ask before a destructive tool runs**
  An estimated 90% of delete-or-pay style tools in the MCP (standard way to give AI tools) registry have no server-side confirmation and 32 of 41 popular hosts and SDKs have no approval step by default, so turn approval on yourself.
  https://arxiv.org/abs/2611.02527

- **MCP tool poisoning tested across 12 agent frameworks**
  Hidden instructions in tool descriptions or tool output succeeded in 22.9% of 9,720 real test runs, and no framework had a deliberate defense, so the model you pick matters more than the framework.
  https://arxiv.org/abs/2611.03555

- **A tool update can turn a trusted tool malicious**
  The ETUDE attack hides harmful code in an update to a tool the agent already trusts and worked 97.6% of the time across seven agent tools including Claude Code, Codex CLI and Gemini CLI, because prompt-injection defenses never see that code.
  https://arxiv.org/abs/2611.01976
