AI digest for 2026-10-02 — 10 items

> **Today's big item:** On 1 October Anthropic added mods to Claude Code. Mods are small TypeScript functions that can rewrite prompts, block or retry tool calls, approve permission requests, hide secrets in tool output and add buttons to the interface. They ship inside plugins and you install them with `/plugin` in the CLI or from the Claude directory.

## New techniques / papers

- **Explicit belief states beat memory for long agent tasks**
  The agent keeps a written note of what it thinks the world looks like and which goals are still open, and this did better than normal memory on all four benchmarks with every model tested.
  https://arxiv.org/abs/2610.01415

- **ActiveSaddler tunes an agent's harness with a changing curriculum**
  Microsoft changes which hard cases it trains the harness (the code that runs the agent's tools) on as it improves, adding 4.4 points on GAIA2 and 7.5 points on Terminal-Bench 2.0.
  https://arxiv.org/abs/2610.00906

## RAG / vector DB tooling

- **MatRAG answers multi-hop questions without building a knowledge graph**
  It groups documents into nested clusters and uses Matryoshka embeddings (vectors you can cut shorter and still use), beating seven baselines while skipping the cost of building a graph or LLM summaries.
  https://arxiv.org/abs/2610.01767

- **CANOPY trims retrieved evidence before it reaches the model**
  For RAG (feeding docs to an LLM) over text, tables, images and video, it cut the evidence tokens sent to the model by 14 to 28% with about the same answer quality.
  https://arxiv.org/abs/2610.00923

## AI security & compliance

- **Agents grab more data than you asked for**
  All seven models tested used tools beyond what the request needed, and a simple self-check that asks the model to justify each call cut this by 43%.
  https://arxiv.org/abs/2610.01508

- **Prompt injection through agent-to-agent messages**
  Across 15 agent and model setups, labelling content that arrives through A2A messages, tools and memory helped agents spot malicious instructions much more often.
  https://arxiv.org/abs/2610.00392
