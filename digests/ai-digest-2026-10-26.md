AI digest for 2026-10-26 — 7 items

> **Today's big item:** Researchers at Forever Security showed that a web page can quietly drop an AGENTS.md or CLAUDE.md file into your Downloads folder, and a coding agent started in that folder will read it and may follow it. In their tests Codex ran the planted payload more than 90% of the time and Claude Code about half the time, which exposed its login token. The simple fix: never start a coding agent in Downloads, and read any instruction file you did not write before an agent sees it.

## New techniques / papers

- **SkillRep: how to help an agent pick the right skill from a big library**
  The paper tests five ways to search a skill library when the user's words do not match the skill description, and a small 0.6B embedding model (turns text into numbers for search) plus LLM query rewriting beat same-size baselines.
  https://arxiv.org/abs/2610.32336

## Ontologies & knowledge graphs for AI

- **Building a knowledge graph where every edge has a source quote**
  LLM agents crawl vendor sites and keep a "customer" or "integration" link only if a five-model voting panel confirms a quote supports it, reaching 0.94 precision, and the code is on GitHub.
  https://arxiv.org/abs/2610.32781

## RAG / vector DB tooling

- **Fine-tune a reranker if you need a reranker**
  Testing six Qwen models on ten search benchmarks, models fine-tuned as rerankers (re-sort search results by relevance) beat general fine-tunes by 5 to 29 points up to 9B, so a generic model is not a free substitute in your RAG (feeding docs to an LLM) pipeline.
  https://arxiv.org/abs/2610.32318

## Agent orchestration frameworks

- **MCP TypeScript SDK 2.4 can serve Agent Skills**
  MCP (Model Context Protocol, a standard way to give agents tools) servers can now publish a folder of skills that clients list, read and verify, and the release also fixes token refresh for Microsoft Entra ID.
  https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/v2.4.0

- **Google ADK 2.13 moves 12 features to stable and adds MongoDB memory**
  The Agent Development Kit can now store sessions in MongoDB and give agents long-term memory by keyword match with no vector index, plus real-time voice with barge-in (user can interrupt).
  https://github.com/google/adk-python/releases/tag/v2.13.0

## Cloud AI service updates

- **Bedrock web search can now be limited to chosen domains**
  The web_search tool on Amazon Bedrock accepts allow or block lists of up to 100 domains and an optional user location, so you can control which sites ground the model's answer.
  https://aws.amazon.com/about-aws/whats-new/2026/10/bedrock-web-search-domain-user-location/

## AI security & compliance

- **A file in Downloads can hijack Codex and Claude Code**
  Coding agents trust instruction files in their working folder, so a planted AGENTS.md can make them install malware or change config, and the authors say there is no single bug for vendors to patch.
  https://forever.security/blog/hijacking-ai-agents-via-downloads-folder
