AI digest for 2026-11-19 — 11 items

> **Today's big item:** On 17 November, attackers published two poisoned versions (1.26.1 and 1.26.2) of Microsoft's `agent-framework` Python package on PyPI. They steal Azure, GitHub and CI credentials every time Python starts, even if you never import the package. PyPI pulled them within an hour, but if anything installed them, pin to 1.26.0 and rotate every secret that machine could see.

## New techniques / papers

- **AnyS1: let a small model make an agent's routine choices**
  A 4B model picks between known options at an agent's routine decision points and hands off to the big model only when unsure, cutting episode cost by 75–91% while keeping task success on three unseen benchmarks.
  https://arxiv.org/abs/2611.23751

- **Simple prompt search matches fancy prompt optimizers**
  Just generating many candidate prompts and keeping the one that scores best matched GEPA, a DSPy prompt optimizer, at 32% lower API cost on average, so try that baseline before paying for a heavier optimizer.
  https://arxiv.org/abs/2611.22605

## RAG / vector DB tooling

- **Microsoft-Embedding-1: one embedding model for text, images and document pages**
  This embedding model (turns content into vectors for search) is built into Azure Cosmos DB, can return one vector or many small vectors per page for sharper matching, and costs $0.12 per million text tokens.
  https://devblogs.microsoft.com/cosmosdb/microsoft-embedding-one/

- **ExecJudges: small programs instead of LLM judges for search relevance**
  An LLM writes a scoring program once per topic, for under $0.50, and that program then labels which documents are relevant about as well as a Claude Sonnet 5.5 judge, so RAG (feeding docs to an LLM) evals stop costing an LLM call per document.
  https://arxiv.org/abs/2611.24849

## AI security & compliance

- **Microsoft's agent-framework package on PyPI was hijacked to steal credentials**
  Versions 1.26.1 and 1.26.2 added a file that runs on every Python start and sends Azure, GitHub Actions and other CI tokens to the attacker, so search your lockfiles, CI logs and images for them, pin 1.26.0 and rotate secrets.
  https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi

- **Evolving agent defences against prompt injection automatically**
  This method uses search to evolve an agent's safety checks against attacks that also evolve, and cut prompt injection (hidden instructions in content the agent reads) success on GPT-4o-mini from 50.4% to 3.0% without hurting normal tasks.
  https://arxiv.org/abs/2611.22583
