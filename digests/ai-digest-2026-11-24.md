AI digest for 2026-11-24 — 14 items

> **Today's big item:** A new study scanned about 145 million GitHub issues, pull requests, comments and READMEs for hidden text aimed at AI coding agents and found 2,281 confirmed cases. Real attacks were rare (about 1 in 3.3 million items), and when replayed against five models they only worked on one small model, 19% of the time. Stripping HTML comments before the agent reads the text stopped every attack, and the code and data are public.

## New model launches

- **inclusionAI publishes Ling-3.2-air with open weights under MIT**
  A 124B MoE (only some sub-networks run per token) model with 5.5B active parameters that reads images and video, aimed at workflow automation and long business documents, though its benchmark gains are vendor-reported.
  https://huggingface.co/inclusionAI/Ling-3.2-air

## New techniques / papers

- **When tools fail, agents make up answers**
  Across 2,100+ runs with injected tool faults, 6–26% of runs ended in a confident made-up answer, and a "verify first" monitor cut that from 17.3% to 10.8%, so check tool errors before trusting agent output.
  https://arxiv.org/abs/2611.28341

- **Using the JSON grammar to speed up structured output**
  Treating the output grammar as an extra drafter for speculative decoding (a small guesser proposes tokens the big model checks) made JSON and tool-call generation 2.66–2.81x faster at batch size 1.
  https://arxiv.org/abs/2611.28349

## Ontologies & knowledge graphs for AI

- **Bosch runs a graph RAG system on a live production line**
  SuSi-RAG mixes knowledge-graph and vector search for RAG (feeding docs to an LLM) on maintenance questions, and over eight months and 10,664 questions it lifted top-1 retrieval from 61.5% to 96.2% against plain vector RAG.
  https://arxiv.org/abs/2611.30588

## RAG / vector DB tooling

- **The abc index makes exact sparse search much faster**
  For learned sparse embeddings (keyword-style vectors a model learns), this exact index was 6.5–84x faster than Qdrant's exact search on MS MARCO, but slower than approximate indexes when you only need the top 10.
  https://arxiv.org/abs/2611.28555

- **SupportChain lets a small model beat a bigger one at multi-hop RAG**
  It merges several quote-backed reasoning chains instead of building an index, and with a 9B reader it scored 63.0 F1 on MuSiQue (a multi-step question set) against 59.2 for the previous best with a 20B reader.
  https://arxiv.org/abs/2611.28519

## Agent orchestration frameworks

- **OpenAI Agents SDK 0.26.0 ships breaking changes**
  Docker sandbox mounts inside the container are now rejected and model-supplied image paths in the Codex tool no longer grant file access, so read the release notes before upgrading.
  https://github.com/openai/openai-agents-python/releases/tag/v0.26.0

- **CrewAI 1.15.45 tightens its server auth**
  The release rejects empty credentials, compares secrets in constant time and drops credentials on cross-origin redirects, so update if you expose a CrewAI server.
  https://github.com/crewAIInc/crewAI/releases

- **Some MCP servers now slip ads into agent tool results**
  A scan found ads on 0.57% of 101,363 open MCP (a standard way to plug tools into LLMs) endpoints, and only 9.3% of those ads were labelled as sponsored, so vet third-party MCP servers before use.
  https://arxiv.org/abs/2611.28911

## Cloud AI service updates

- **AWS WAF can now find and guard LLM, MCP and A2A endpoints**
  It spots AI endpoints behind API Gateway, load balancers and CloudFront, blocks malformed MCP and A2A (agent-to-agent protocol) messages, and can call Bedrock Guardrails to catch prompt injection (hidden instructions in input), at extra cost.
  https://aws.amazon.com/about-aws/whats-new/2026/11/waf-ai-endpoint-discovery-protection/

- **Anthropic deprecates Claude Opus 4.5 on the API**
  `claude-opus-4-5` retires on 22 January 2027 and Anthropic recommends Claude Opus 5.5, so plan the switch now if you still pin the old model.
  https://platform.claude.com/docs/en/models/opus-5-5/migration-guide#migrating-from-claude-opus-45

## AI security & compliance

- **Hidden prompts aimed at coding agents are real but rare on GitHub**
  The study found 2,281 confirmed cases in about 145M items, attacks worked only on one small model (19% of the time), and none worked once HTML comments were stripped.
  https://arxiv.org/abs/2611.28763

- **Web agent defences fail against adaptive image-based attacks**
  On 360 test pages across 10 real sites, adaptive visual prompt injection (instructions hidden in what the agent sees) beat 21 defence setups about 92% of the time.
  https://arxiv.org/abs/2611.29268

- **Commercial AI agents remember more than users can see**
  An audit of five agents found the visible memory showed about 20% fewer personal details than the agents stored, and all five still leaked data after deletion, which matters for GDPR erasure requests.
  https://arxiv.org/abs/2611.29804
