AI digest for 2026-11-18 — 11 items

> **Today's big item:** On 17 November, OpenAI released GPT-6.2 Astra, a model for hard, long tasks, and GPT-6.2 Sol, a cheaper model for everyday agent work. Both are in the API as `gpt-6.2-astra` and `gpt-6.2-sol`, and Astra now costs $8 / $40 per million input / output tokens, 20% less than GPT-6 Astra. OpenAI added tighter limits on risky cybersecurity requests, and independent testers report only small coding gains, so test it on your own tasks before switching.

## New model launches

- **OpenAI releases GPT-6.2 Astra and GPT-6.2 Sol**
  Astra ($8 / $40 per million tokens) targets hard multi-step work, while Sol ($2 / $10) nearly matches it on OpenAI's coding benchmark at about a fifth of the cost, so Sol is the one to try first for agent workloads.
  https://openai.com/index/introducing-gpt-6-2-astra-sol/

- **Alibaba releases Qwen4-Max with a 1M-token context window**
  A closed-weights MoE model (many expert sub-networks, only some used per word) with about 71B active parameters, image input and a 1M-token context window (how much text it can read at once), available now through the QwenCloud API, with smaller open-weight Qwen4 models promised soon.
  https://www.alibabacloud.com/press-room/alibaba-unveils-qwen4-max

## New techniques / papers

- **JET: teaching tool-using agents to stop searching once they know enough**
  This fine-tuning (extra training on your own examples) method cuts each training example at the point where the agent already has enough information, which reduced tool calls by 11–33% on code-repository Q&A with 8B models while keeping most of the accuracy.
  https://arxiv.org/abs/2611.22539

- **A simple RAG memory matches complex agent memory systems**
  BRIDGE, a minimal agent memory built on RAG (feeding docs to an LLM) with keyword plus vector (meaning-based) search, matches the best published results on two memory benchmarks, but new tests show no memory design wins at every kind of recall.
  https://arxiv.org/abs/2611.22179

- **Reversibility classes: can your agent undo what a tool just did?**
  The authors rate 536 tools across 20 MCP (a standard way to plug tools into LLMs) servers on a five-level "how undoable is this" scale, and a guard built on it stopped all 29 matching attack runs, versus 18 for a simple read/write check.
  https://arxiv.org/abs/2611.22075

## Ontologies & knowledge graphs for AI

- **Microsoft Foundry IQ adds knowledge graphs and a retrieval model**
  Now in preview, Foundry IQ can build knowledge graphs (facts stored as linked entities) across your documents so agents follow relationships instead of only fetching loose passages, and a new Microsoft-Retriever-1 model plans multi-step searches over your own data.
  https://azure.microsoft.com/en-us/blog/introducing-the-new-microsoft-iq-putting-your-organizations-intelligence-to-work-in-every-agent

## RAG / vector DB tooling

- **StitchRAG: shorter RAG contexts by compressing each retrieved passage**
  It decides how much to shrink each passage, keeps sentences with likely answers and query keywords, and joins them into readable text with a diffusion model (a model that refines text in steps), beating multi-step and compression baselines on five Q&A benchmarks.
  https://arxiv.org/abs/2611.22766

## Agent orchestration frameworks

- **Microsoft Copilot SDK 2.0: the Copilot agent harness, rebuilt in Rust**
  The MIT-licensed SDK (formerly GitHub Copilot SDK) runs many isolated agent sessions in one process from TypeScript, Python, Go, .NET, Java or Rust, with per-user identity, your own tools or MCP servers, and sessions you can resume on another machine.
  https://commandline.microsoft.com/microsoft-copilot-sdk-2-0-github/

## Cloud AI service updates

  With the new linked billing beta, a request can set `billing_policy` so the customer's own Claude organization pays, and customers can cap spend or unlink your app in the Claude Console.
  https://platform.claude.com/docs/en/release-notes/api

  Multi-turn evals (automated quality tests), production insights and an agent optimizer are now generally available, and model training from real production signals is in preview, so you can tune agents against what users actually do.
  https://news.microsoft.com/events/ignite/2026/book-of-news/

## AI security & compliance

- **Eight in ten LLMs leaked a secret hidden in their system prompt**
  An agent-driven test got 296 of 363 OpenRouter models to reveal a flag stored in the system prompt (the developer's hidden instructions), often just by switching to French or another language, so never put secrets in a prompt and enforce rules in code.
  https://arxiv.org/abs/2611.21956
