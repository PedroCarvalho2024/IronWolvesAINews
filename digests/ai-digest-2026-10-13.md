## New techniques / papers

- **AgentSWE tests whether coding agents can build working agents**
  On 25 tasks for creating, editing and tuning agents, no coding agent fully delivered what was asked, often overfitting to visible tests or claiming it was done when it was not.
  https://arxiv.org/abs/2610.13361

- **SEEDS lets search agents preview documents before reading them**
  A search agent looks at a short preview of each retrieved document and only pulls the useful ones into its context, which improved results on nine QA benchmarks while reading less text.
  https://arxiv.org/abs/2610.12932

- **TerminalHorizon trains agents on long command-line tasks**
  The authors auto-generated 1,500 long terminal tasks and fine-tuned (further trained on your own data) Qwen3.5-27B on them, improving it on all 12 agent and reasoning benchmarks they tried.
  https://arxiv.org/abs/2610.13166

## Interesting GitHub repos

- **REA lets AI agents reverse engineer apps and binaries through MCP**
  An MIT-licensed toolkit, trending at the top of GitHub today, that gives Claude Code, Codex, Cursor or other MCP (a standard way to plug tools into LLMs) agents local tools for inspecting binaries, APKs, Electron apps and network captures.
  https://github.com/morluto/rea
