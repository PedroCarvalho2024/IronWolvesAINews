AI digest for 2026-09-28 — 6 items

> **Today's big item:** Google released ADK 2.10.0, its Python framework for building agents. It adds a MongoDB toolset for vector and hybrid search, plus new eval metrics that track how long an agent run takes, how many tokens it uses and how many model calls it makes. If you build agents on ADK, you can now measure cost and speed in the same place you test quality.

## New techniques / papers

- **Coding agents waste up to 22.75% of their cost on repeated work**
  The study finds agents often re-read files, rewrite near-identical scripts and re-run tests, and hand-written skills (reusable instructions) cut cost by up to 41.73%.
  https://arxiv.org/abs/2609.30725

- **LW2S learns which steps a multi-agent workflow can skip**
  It checks what happens when each step is left out, then skips the ones that do not help, using fewer tokens with the same or better accuracy.
  https://arxiv.org/abs/2609.30734

- **New benchmark tests what agents let into shared memory**
  When several agents share one memory, only accepting claims based on their declared source kept false facts at 6–9%, versus 22–47% for other policies.
  https://arxiv.org/abs/2609.30813

## Ontologies & knowledge graphs for AI

- **Knowledge graphs used to check if LLMs really understand context**
  A new score called S3KG uses knowledge graphs to compare both structure and meaning, and it beat the best baseline by up to 7.6 F1 points across nine benchmarks.
  https://arxiv.org/abs/2609.30484

## Agent orchestration frameworks

- **Google ADK 2.10.0 adds MongoDB search and cost metrics**
  The release adds vector and hybrid search through MongoDB, eval metrics for duration, tokens and model calls, and limits on how many skills an agent keeps active.
  https://github.com/google/adk-python/releases/tag/v2.10.0

## AI security & compliance

- **Skill cascading attacks split one harmful goal across several harmless-looking skills**
  Each skill passes a security scan on its own, but together they do harm, so check how the skills you install work together, not just one by one.
  https://arxiv.org/abs/2609.30383
