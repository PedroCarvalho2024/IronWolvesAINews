AI digest for 2026-11-26 — 12 items

> **Today's big item:** Google made its hosted Workspace MCP servers and the official Workspace CLI generally available, covering Gmail, Drive, Docs, Sheets, Slides, Calendar, Chat and Tasks. From 1 February 2027, AI agents must reach Workspace data through MCP instead of calling the Workspace REST APIs directly. If you have an agent that talks to Gmail, Drive or Calendar today, plan the switch now.

## New model launches

- **Ant Group releases Ling-3.2-air as open weights under MIT**
  A multimodal (text, images and video) MoE (only some sub-networks run per token) model with 124B total and 5.5B active parameters, whose self-reported scores on office-automation tasks jump from 15.7% to 61% over the previous version.
  https://huggingface.co/inclusionAI/Ling-3.2-air

- **Cognition releases SWE-2.1, the coding model behind Devin**
  Trained with RL (learning from trial and reward) on Kimi K3, it roughly doubles its predecessor on Terminal-Bench 4.1 (24.2 to 50.0), but it is only available inside Devin, with no API or downloadable weights.
  https://cognition.com/blog/swe-2-1

## New techniques / papers

- **CARE-OPD makes distillation cheaper for long-running coding agents**
  This on-policy distillation (a small model learning from a bigger one on its own attempts) method reached 59.5% on SWE-bench Verified while cutting training time by 45% and environment actions by 44%.
  https://arxiv.org/abs/2611.34756

- **NVIDIA's TimeTravelContainer forks a running agent sandbox in place**
  A rootless container runtime that copies a live container (processes, memory, files and network) so an agent can try several paths from the same point, with 84.1x faster cloning and open-source code from NVlabs.
  https://arxiv.org/abs/2611.32255

## RAG / vector DB tooling

- **OpenSearch releases its own open dense and sparse embedding models**
  The dense (one vector of numbers per text) opensearch-neural-embed-v1 has 598M parameters and is built on Qwen3-Embedding-0.6B, and the sparse (weights over a word vocabulary) asym-v1 encodes queries in about 27 ms on one CPU thread, both on Hugging Face.
  https://opensearch.org/blog/introducing-new-opensearch-sparse-and-dense-retrieval-models/

- **ConTra trains small models to add context to RAG chunks**
  For RAG (feeding docs to an LLM), it trains a 2B model to write a short context prefix for each chunk before indexing, beating a prompted 9B model by up to 3.15 points while indexing faster, with code on GitHub.
  https://arxiv.org/abs/2611.34366

## Agent orchestration frameworks

- **Google Workspace MCP servers are GA, and REST access for agents ends 1 February 2027**
  MCP (a standard way to plug tools into LLMs) servers now cover eight Workspace apps, agents must flag their OAuth client as "AI-powered agent", and usage above free daily limits will be billed from 1 April 2027.
  https://workspaceupdates.googleblog.com/2026/11/mcp-servers-cli-standardized-usage-tiers-now-available.html

- **CrewAI 1.15.45 fixes credential handling**
  The release drops credentials on cross-origin redirects, rejects empty credentials in server auth and adds saving HTML or markdown output as a PDF, so it is worth upgrading if you run a CrewAI server.
  https://github.com/crewAIInc/crewAI/releases

- **Google ADK 2.15.1 keeps Claude settings working on Anthropic SDK 2.x**
  This patch keeps Claude sampling settings (temperature and similar) working across Anthropic SDK 1.x and 2.x and reverts a change to how streamed A2A (agent-to-agent protocol) output is saved.
  https://github.com/google/adk-python/releases

## Cloud AI service updates

- **Anthropic explains how it moved the Claude Messages API from Python to Rust**
  The switch already finished in September and cut CPU per request by about 70% and median time to first token by about 20%, and the post shows how Claude agents checked the new code against shadowed (copied) production traffic.
  https://www.anthropic.com/research/migrating-api-to-rust

## AI security & compliance

- **MINE defends RAG against hidden instructions without training**
  A training-free defence against indirect prompt injection (hidden instructions inside retrieved documents) that gave the best accuracy-security trade-off on four datasets and still held up against an adaptive attacker.
  https://arxiv.org/abs/2611.34188

- **UK financial regulator sets out what it expects from agentic AI**
  The FCA says UK financial firms stay responsible for agents they build or buy, must know how to detect and limit customers' own AI agents, and that tech providers may need authorisation if their agents give advice or make payments.
  https://www.fca.org.uk/firms/innovation/ai-approach/agentic-ai
