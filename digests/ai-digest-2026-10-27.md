> **Today's big item:** OpenAI released GPT-6.1 Terra, a mid-tier model that is strong at reading images and at computer use (the model clicks and types in apps for you). The API price is half that of GPT-5.6 Terra, at $1 per million input tokens and $5 per million output tokens, and it reads up to 1 million tokens. ## New model launches

- **OpenAI releases GPT-6.1 Terra**
  A cheaper mid-tier model for vision, computer use and writing, available in the API as `gpt-6.1-terra`, and worth testing if you pay for GPT-5.6 Terra today.
  https://openai.com/index/introducing-gpt-6-1-terra/

## New techniques / papers

- **Picking agent memories like a recommender picks products**
  AgentMemRec chooses which saved memories go into the prompt with recommender-system ranking and no LLM calls, beating A-Mem and HippoRAG 2 by 10 to 31 points on LongMemEval.
  https://arxiv.org/abs/2610.34673

- **DynaFlow: a main agent that writes the plan for its sub-agents**
  The main agent writes small programs that run fixed sub-agents in order or in parallel and check their output, and training only that agent beat the best baseline by 10.9 points across six benchmarks.
  https://arxiv.org/abs/2610.34467

## RAG / vector DB tooling

- **HyperAddress: multi-hop retrieval with no text generation at query time**
  It uses a few attention heads to walk a graph of linked facts for questions that need several documents, giving +7.4 points All@5 and answers twice as fast as the best baseline in RAG (feeding docs to an LLM).
  https://arxiv.org/abs/2610.35412

## Agent orchestration frameworks

- **LangGraph 1.2.18 changes the default snapshot interval**
  Long threads now save a full checkpoint every 100 updates instead of 1,000, so reads get faster but storage grows, and `snapshot_frequency=1000` keeps the old behaviour.
  https://github.com/langchain-ai/langgraph/releases/tag/1.2.18

- **Pydantic AI 2.62 renames hosted MCP tools by default**
  Hosted MCP (Model Context Protocol, a standard way to give agents tools) tool names now get the service name as a prefix, and new error types tell auth failures apart from missing models, so check your tool-name matching before upgrading.
  https://github.com/pydantic/pydantic-ai/releases/tag/v2.62.0

## AI security & compliance

- **627 malicious agent skills found on ClawHub**
  Researchers scanned 66,157 public agent skills (instruction packs an agent loads) and confirmed 627 were malicious, so read a third-party skill before you install it.
  https://arxiv.org/abs/2610.33489

- **Fake tool descriptions can fool agents 92% of the time**
  An attack writes tool descriptions that look harmless, so the agent picks the attacker's tool, and it got past five tool-malware detectors and human reviewers.
  https://arxiv.org/abs/2610.33182
