## New techniques / papers

- **Batched GEPA: test several prompt changes at once, finish in half the time**
  GEPA (a tool that rewrites prompts from failed runs) now tries a batch of candidates per step, which cut run time by half or more in most runs and raised one test score from 49.0% to 60.0%.
  https://arxiv.org/abs/2610.36774

- **TAO: smarter GPU scheduling for agents that wait on tools**
  A scheduler for serving agents that predicts when tool results will be ready and places sessions on GPUs accordingly, cutting latency by up to 26.8% against the best baseline.
  https://arxiv.org/abs/2610.37230

## Ontologies & knowledge graphs for AI

- **FoG: train knowledge-graph agents to show their evidence, not just the answer**
  It rewards a small agent for each supporting fact it fetches from a knowledge graph (a database of facts linked as entity-relation-entity), and 3B–4B models trained this way beat much larger baselines.
  https://arxiv.org/abs/2610.37405

- **GraphRAGProv: trace each GraphRAG answer back to the source text**
  It records exactly which extracted facts and source sentences produced each answer, and on 400 test cases it found extraction errors even where the final answer was right.
  https://arxiv.org/abs/2610.37237

## RAG / vector DB tooling

- **LanceDB 0.41.0 turns off remote model code by default**
  Saved embedding settings that load remote model code or custom endpoints now need explicit approval in your code, so check the migration note before you upgrade.
  https://github.com/lancedb/lancedb/releases/tag/v0.41.0

- **Weaviate 1.40.3 adds missing auth to backup handlers**
  A patch release that adds basic auth to backup handlers that lacked it and fixes several hybrid search (keyword plus vector) bugs, so upgrade if you self-host.
  https://github.com/weaviate/weaviate/releases/tag/v1.40.3

- **SpectRAG: pick chunks as a graph, not one by one**
  For multi-hop questions (answers that need several documents), it links chunks by similarity, shared entities and citations, then fills a fixed token budget, and found more of the needed evidence than plain vector search.
  https://arxiv.org/abs/2610.36991

## AI security & compliance

- **Many chatbot websites leak your conversations to ad trackers**
  An audit of 42 AI chat sites found 21 sent conversation titles and 9 sent full user prompts to third-party trackers, a GDPR (EU data protection law) risk if you embed analytics in your own chat UI.
  https://arxiv.org/abs/2610.37467
