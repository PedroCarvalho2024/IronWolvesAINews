> **Today's big item:** OpenAI released GPT-6 Cyber, a model built for security work, on November 5. OpenAI says it beats the general GPT-6 Astra on most cyber tasks, and it is the model behind the 948 Linux kernel root bugs reported this week. Only approved members of OpenAI's Daybreak Red security program can use it for now, with wider Daybreak Red access promised over the coming weeks.

## New model launches

- **OpenAI releases GPT-6 Cyber for vetted security teams**
  A security-focused model that found 81 high-severity Firefox bugs and working exploits for 948 Linux kernel flaws, available only to approved Daybreak Red customers because attackers could misuse it.
  https://openai.com/index/introducing-gpt-6-cyber/

## New techniques / papers

- **EnvOpt: tune the agent's environment, not just the model**
  Automatically rewriting how shared data (Slack, docs, tickets) is presented to an agent cut Claude Haiku 4.5's cost by 72.7% and raised its pass rate by 14.34% on AutomationBench, with no graders or reference answers needed.
  https://arxiv.org/abs/2611.07372

## Ontologies & knowledge graphs for AI

- **GenVer checks knowledge graph facts by turning them into sentences**
  It finds wrong facts in a knowledge graph (facts stored as subject–relation–object triples) by scoring each triple together with a generated plain-English version of it, reaching 88.56% to 91.52% accuracy on FB15k-based test sets.
  https://arxiv.org/abs/2611.07780

## RAG / vector DB tooling

- **Google's GINGER library speeds up vector search**
  This open-source C++ library for approximate nearest neighbour search (finding the closest vectors fast) reports 1.8x more queries per second than the fastest competitor at 95% recall, and its new quantiser (a way to store vectors in fewer bits) uses 2.6x less memory.
  https://arxiv.org/abs/2611.08306

- **A small model that screens web pages before your LLM reads them**
  For RAG (feeding docs to an LLM) over web results, a 4B open-weight "gate" model cut prompt injection success from 27.9% to 5.7% at 76 ms per page while keeping answer accuracy about the same.
  https://arxiv.org/abs/2611.08325

## AI security & compliance

- **SPILLWAY blocks injected targets in agent tool calls**
  It only lets an agent send to a recipient or account that came from the user's task or from a typed field of a read-only tool, which stopped every standard templated prompt injection (hidden instructions in data the model reads) in the tests, with code on GitHub.
  https://arxiv.org/abs/2611.07222

- **Signing requirements between agents is not enough**
  Cryptographically signing the list of requirements passed between subagents cut unsafe commits from 69.4% to 9.0%, but one injected line before signing pushed violations as high as 75%, so check the extraction step too.
  https://arxiv.org/abs/2611.07483
