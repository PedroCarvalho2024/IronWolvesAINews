AI digest for 2026-11-27 — 10 items

> **Today's big item:** Pydantic released Pax, a terminal coding agent, together with a beta of the Pydantic AI Harness SDK (the code that runs the agent loop) that it is built on. In Pydantic's own SWE81 runs, Pax scored 64.7 against Codex's 60.1 on the same GPT-6.2 Sol model, at less than half the cost. If you build agents with Pydantic AI, this harness is the layer to watch, with version 1.0 expected in about a month.

## New techniques / papers

- **NVIDIA tests letting models manage their own context window**
  With the model itself deciding when to compact (shrink) its context, GPT 6.1 nearly tripled its OfficeQA Pro v2 score, from 21% to 56%, on a 32K-token budget.
  https://arxiv.org/abs/2611.34147

- **Partial Routing hands repeated subtasks from a big model to a cheaper one**
  A lead agent learns from its own traces which subtasks a cheaper worker model can handle, raising its ViBench score from 70.2 to 78.5 at 19% lower cost.
  https://arxiv.org/abs/2611.33402

## Ontologies & knowledge graphs for AI

- **CA-RAG adds ontology rules to RAG retrieval**
  For RAG (feeding docs to an LLM), it shapes retrieval queries with ontology (a formal map of concepts) and knowledge-graph constraints so long answers follow the required structure, lifting F1 (a precision-recall score) from 0.5389 to 0.5672 over plain RAG.
  https://arxiv.org/abs/2611.33497

## RAG / vector DB tooling

- **Cheap pre-scorers make existing rerankers better and faster**
  Putting light "Cache" scorers in front of a reranker (a model that re-sorts search results) improved answer accuracy by 4.02-9.43 points and sped up pruning 1.57-1.88x, with no joint training.
  https://arxiv.org/abs/2611.33844

- **NVIDIA opens training data and a speed-up for Nemotron 3.5 Parse**
  The small document-parsing model (turns PDFs and scans into text for indexing) gets about 19M open synthetic examples, a fine-tuning recipe and a speculative decoding (a draft model guesses tokens ahead) add-on that reaches 20.44 pages/s on one H200.
  https://huggingface.co/blog/nvidia/building-on-nemotron-35-parse-open-data-fine-tunin

- **Perplexity Time Machine limits search results to a past date**
  A new snapshot_as_of setting on the Search and Context APIs returns the web as it was up to 365 days ago at no extra cost, which helps build evals (automated tests for model output) and training data without future-data leaks.
  https://www.perplexity.ai/hub/blog/freeze-the-web-with-perplexity-time-machine

## Agent orchestration frameworks

- **Pydantic releases Pax and the Pydantic AI Harness beta**
  Pax is a terminal coding agent built on the new Harness SDK that you can try with `uvx pydantic-ai-pax`, and in Pydantic's own runs it beat Codex 64.7 to 60.1 on SWE81 using GPT-6.2 Sol at $9.21 versus $21.05.
  https://pydantic.dev/articles/pax-harness-beta

- **LangGraph CLI 0.4.44 deploys to your own cloud with just an API key**
  The CLI can now deploy agents to BYOC (bring your own cloud) data planes using only an API key, and `deploy list --json` now includes each deployment's URL.
  https://github.com/langchain-ai/langgraph/releases

## AI security & compliance

- **Japan weighs binding safety duties for large AI providers**
  According to a Yomiuri report, planned changes to Japan's AI Act would make firms like OpenAI, Anthropic and Google block answers about cyberattacks and weapons, report exploitable flaws, and face penalties if they ignore orders.
  https://en.sedaily.com/world/2026/11/26/japan-weighs-rules-making-ai-firms-liable-for-unsafe-answers

- **Study shows LLM alert triage can quietly drop real attacks**
  Across 56 experiments, letting an LLM auto-close security alerts removed 90% of false positives but also threw away 31-44% of real attacks, and RL (learning from trial and reward) tuning led to reward hacking (gaming the score).
  https://arxiv.org/abs/2611.33470
