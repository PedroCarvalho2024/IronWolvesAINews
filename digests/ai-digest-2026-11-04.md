AI digest for 2026-11-04 — 9 items

> **Today's big item:** Since November 3, text from Claude Mythos 5, Claude Opus 4.7 and Claude Sonnet 4.6 carries Anthropic's hidden text watermark, a statistical pattern in word choice that adds no tokens and does not change the meaning. On Sonnet 4.6, requests that set `temperature`, `top_p` or `top_k` to non-default values might not get the watermark. If you need it (for example for EU AI Act marking), check that your framework or client library is not setting those values for you.

## New techniques / papers

- **Route Anything: how much does picking a model per request really help?**
  Across 374,401 scored runs, perfect per-request routing (sending each request to the best model for it) beat the best single model by 5.4 points, but learned routers gained only 0.3 points, so test a router before you trust it.
  https://arxiv.org/abs/2611.05275

- **Swapping the LLM judge changes which system wins**
  In a preregistered study, LLM judges (models used to grade other models) agreed weakly with human votes, with a median Cohen's kappa of 0.22, and system rankings changed when the judge changed, so do not rely on a single judge model.
  https://arxiv.org/abs/2611.04090

## RAG / vector DB tooling

- **Long context is not what breaks retrieval, competing facts are**
  On Qwen2.5-1.5B, neutral filler up to 32K tokens caused no loss, but evidence-style distractors dropped accuracy to 0.16–0.33, so in RAG (feeding docs to an LLM) remove near-duplicate and conflicting chunks rather than just cutting length.
  https://arxiv.org/abs/2611.04169

## AI security & compliance

- **claude-mem uploaded 30 days of prompts without asking, now fixed**
  Since v15.2.0 the browser setup of this popular agent-memory tool sent the full text of recent prompts, with project names and folder paths, to cmem.ai, and v15.8.3 adds a consent screen but does not delete data already uploaded.
  https://github.com/thedotmack/claude-mem/releases/tag/v15.8.3

- **Parameter poisoning: right tool, wrong arguments**
  Attacks that trick an agent into calling a correct tool with attacker-chosen parameters succeeded 93.06% of the time, and the proposed AuthorityFlow defense cut that to 9.03% while keeping 82.64% of normal task success.
  https://arxiv.org/abs/2611.04673

- **Nine ways prompt injection attacks differ**
  A new taxonomy of prompt injection (hidden instructions in content an AI reads) shows that most of nine existing benchmarks cover only a small part of the attack space, which helps when choosing what to test your agent against.
  https://arxiv.org/abs/2611.04672
