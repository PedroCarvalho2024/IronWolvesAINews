AI digest for 2026-11-12 — 7 items

> **Today's big item:** Google launched the Gemini Decisions API on 11 November, powered by a new model called Gemini Decision 1 (`gemini-decision-1`). It does not write text: you send one input and up to 1,000 yes/no, multiple-choice or rubric questions, and it returns a score with a confidence value for each. It costs $0.10 per million input tokens with no output charge, which makes it a cheap option for routing, policy checks and picking tools in agent code.

## New model launches

- **Alibaba opens a two-week preview of Qwen4-Max**
  The first Qwen4 model reads text, images and video with a 1M-token context window (how much text it can read at once), but it is only on Alibaba's Token Plan and will be retired on 25 November, so treat it as a test drive, not something to build on.
  https://docs.qwencloud.com/developer-guides/getting-started/latest-model

- **MiniMax publishes open weights for H3-Image**
  An image generation and editing model that MiniMax says makes 4K images in under 10 seconds, but its licence excludes the EU, UK, US and South Korea, so European teams need separate permission from MiniMax to use it.
  https://huggingface.co/MiniMaxAI/MiniMax-H3-Image

## New techniques / papers

- **Where multi-agent runs actually go wrong**
  A study of 95 failed runs found mistakes usually start early, and in 72% of them the log already held evidence against the mistake that no agent acted on, so adding a reviewer that checks that evidence may help more than adding agents.
  https://arxiv.org/abs/2611.13254

## Ontologies & knowledge graphs for AI

- **Turning BPMN process diagrams into LangGraph agent workflows**
  The authors convert business process models (BPMN, a standard flowchart format) into runnable LangGraph workflows, using a knowledge graph of the company's processes and people as context, with LLM calls only at chosen steps; it is a design proposal with no benchmark results yet.
  https://arxiv.org/abs/2611.13196

## Agent orchestration frameworks

- **LangChain 1.5.0 adds a model router and drops Python 3.10**
  A new beta `ModelRouterMiddleware` uses a small classifier to pick which model handles each request, and you now need Python 3.11 or newer (3.10 users stay on 1.4.x).
  https://github.com/langchain-ai/langchain/releases/tag/langchain%3D%3D1.5.0

## Cloud AI service updates

- **Google launches the Gemini Decisions API**
  It scores up to 1,000 fixed-choice questions about one input (text, images, audio, video or PDF) in a single call for $0.10 per million input tokens, and is available now in the Gemini API and AI Studio, with Google Cloud support "coming soon".
  https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/

## AI security & compliance

- **Railway breach: attackers hunted for AI API keys in environment variables**
  Railway's full incident report says attackers decrypted customer secrets and searched them for AI provider keys, which then ran up about $740,000 in stolen usage, so set spending limits on your AI keys and rotate them if they lived on Railway.
  https://blog.railway.com/p/incident-report-october-security-incident
