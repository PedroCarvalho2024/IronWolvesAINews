## New techniques / papers

- **Just-in-Time Memory lets agents build memory when they need it**
  Instead of summarising what to remember at the end of a task, JitMem keeps the full history and writes a task-specific summary at read time, which raised scores by about 16 points on ALFWorld and WebShop.
  https://arxiv.org/abs/2609.27334

## Interesting GitHub repos

- **Univer 1.0 ships an office SDK that agents can drive**
  One open-source SDK for sheets, docs, slides and PDFs, now with an AI SDK so a TypeScript agent can edit documents, change formulas and create charts.
  https://github.com/dream-num/univer/releases

## Ontologies & knowledge graphs for AI

- **ArticleMiner builds knowledge graphs from science papers**
  It uses an ontology (a formal list of concepts and how they relate) plus several parsers and an LLM to pull facts from papers and their tables and supplementary files, and it beat a plain LLM baseline on all four test domains.
  https://arxiv.org/abs/2609.25607
