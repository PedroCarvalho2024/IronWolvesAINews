AI digest for 2026-11-05 — 12 items

> **Today's big item:** Moonshot AI published the full weights of Kimi K3.1 Pro on Hugging Face. It is a 2.8-trillion-parameter MoE model (only some "expert" parts run per token), with 104B parameters active per token and a 1M-token context window. Before this you could only use it through APIs. It ships under Moonshot's own Kimi K3.1 Pro License, not a standard open-source licence, so read the terms before you self-host it.

## New model launches

- **Moonshot releases Kimi K3.1 Pro weights**
  You can now download and self-host the 2.8T-parameter MoE model (104B active, 1M-token context), but it needs a very large GPU cluster and has its own licence.
  https://huggingface.co/moonshotai/Kimi-K3.1-Pro

- **Ricursive releases Ripple-65B Preview under Apache 2.0**
  This 65B dense (every parameter used for every token) open-weights model is built for agentic coding, scores 80.52 on TerminalBench 2.1 by the company's own numbers, and is small enough to run on an NVIDIA DGX Spark.
  https://huggingface.co/ricursiveAI/Ripple-65B-Preview

## New techniques / papers

- **Same model, different agent harness, different ranking**
  Four open-weight models ran through five harnesses (the code around a model: prompts, tools, loop) on banking-rule cases, and the harness alone moved one model from first to last place with an 11.5-point swing, so test your harness and not just your model.
  https://arxiv.org/abs/2611.06116

## Interesting GitHub repos

- **NVIDIA auto-ontology is trending on GitHub**
  This Apache-2.0 tool builds an ontology (a map of business terms and how they relate) over databases like Postgres, Snowflake and DuckDB, so agents can turn questions into checked SQL through MCP or a REST API.
  https://github.com/NVIDIA/auto-ontology

## Ontologies & knowledge graphs for AI

- **ArcRAG lets the model plan its own graph queries**
  For RAG (feeding docs to an LLM) over a knowledge graph, ArcRAG builds a small per-question view of the graph, plans multi-hop steps and runs and repairs them as Cypher (the Neo4j query language), and keeps working when the graph is built in different ways.
  https://arxiv.org/abs/2611.06481

## RAG / vector DB tooling

- **RAGCompass picks the right retriever for each question**
  It uses a fine-tuned reranker (a model that re-scores search results) to choose which retriever to trust per query, and improved answer F1 by 28% relative to the best single fixed retriever.
  https://arxiv.org/abs/2611.05596

## Agent orchestration frameworks

- **LangGraph 1.2.20 adds a strict resume mode**
  Each `interrupt()` (a pause to wait for human input) in a task now gets its own id, and a new strict mode refuses stale answers so an old approval cannot resume the wrong pause.
  https://github.com/langchain-ai/langgraph/releases/tag/1.2.20

- **LangChain core 1.7.5 standardises model refusals**
  When a model refuses, you now get one standard refusal content block (Gemini safety blocks included) instead of provider-specific shapes, and `langchain` 1.4.9 now requires this version.
  https://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.7.5

## AI security & compliance

- **OpenAI's agents found 948 Linux kernel root bugs**
  OpenAI says an automated agent pipeline on an unreleased cyber model found and patched 948 distinct flaws that let a local user become root, for about $1.2M in API credits, and it is sending reports to kernel maintainers.
  https://openai.com/index/a-thousand-fewer-paths-to-root/

- **Office files can show the AI something different from what you see**
  Text extractors pass 19 kinds of hidden content in .docx, .xlsx and .pptx files to the model, and five attacks built on this fooled every assistant and coding agent tested, which matters if your RAG pipeline ingests Office files.
  https://arxiv.org/abs/2611.05806

- **Pydantic AI 2.66.0 fixes two high-severity issues**
  Upgrade to 2.66.0 or 1.107.10 if your agents use `web_fetch_tool` on URLs an attacker can influence, and to `pydantic-ai-harness` 0.66.0 if you use `redact_secrets`, where crafted text could freeze the event loop.
  https://github.com/pydantic/pydantic-ai/releases/tag/v2.66.0
