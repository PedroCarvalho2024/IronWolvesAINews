## New techniques / papers

- **Agents that retry failed code can do real damage**
  In AppWorld traces from ten models, about 24.6% of retries after a partly failed step caused harm such as duplicate actions or deleted data, and a simple duplicate-call check caught only 41% of it.
  https://arxiv.org/abs/2611.31554

- **Training agents on one harness hurts them on others**
  "Harness rehearsal" (extra training on how to use a tool interface) took Qwen3-4B from 8.5% to 58.8% on multi-turn function calling when mixed with normal task data, and code and data are public.
  https://arxiv.org/abs/2611.31427

## RAG / vector DB tooling

- **Tencent releases OmniEVIE, an open multi-modal embedding model**
  A 4.5B multi-vector embedding (many small vectors per item instead of one) model for text, images, documents and video that stores about 8.8 GiB per million records and answers in 54 ms at 1M records on one thread.
  https://arxiv.org/abs/2611.32203

- **SOARS reranks search results inside agent loops**
  A fast, training-free reranker (re-sorts retrieved results by relevance) that raised a search agent's accuracy on BrowseComp-Plus from 73.9% to 84.7% while cutting search calls from 23 to 14.
  https://arxiv.org/abs/2611.32917

## AI security & compliance

- **ContextLure turns harmless chat history into prompt injection**
  By reading earlier normal conversation and rewriting it into an urgent request, this prompt injection (hidden instructions in input) attack reached 67.4% success on AgentDojo and 87.3% on InjecAgent.
  https://arxiv.org/abs/2611.31424

- **Conartist beats defences in computer-using agents**
  Multi-step injections that blend into the real task got past consistency checks and risk audits, with 66.67% success on a Reddit GUI benchmark, 29 points above the previous best attack.
  https://arxiv.org/abs/2611.29977
