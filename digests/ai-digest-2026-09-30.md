AI digest for 2026-09-30 — 12 items

> **Today's big item:** At DevDay on 29 September, OpenAI released GPT-6.1 Sol, a mid-tier model it says comes close to its top model GPT-6 Astra at about a fifth of the price. The same day AWS put it on Bedrock and launched a preview of Bedrock Managed Agents, built on OpenAI's Agents API.

## New model launches

- **OpenAI releases GPT-6.1 Sol at DevDay**
  An upgrade to GPT-6 Sol aimed at coding agents and computer use, available in the API as `gpt-6.1-sol` and already on Amazon Bedrock.
  https://openai.com/index/devday-2026-recap/

## New techniques / papers

- **HybridCUA lets computer-use agents mix clicks and shell commands**
  A 9B model that picks between the GUI and the command line for each step, and scores 53.6% on the OSWorld desktop benchmark, 14.8 points above its base model.
  https://arxiv.org/abs/2609.38008

- **WideSWE tests coding agents on changes across several repos**
  Agents solved only about 11% to 43% of tasks that need linked edits in more than one repository, so keep a human check on cross-repo changes.
  https://arxiv.org/abs/2609.33382

- **Diverse fine-tuning examples help models generalise after RL**
  Picking SFT (supervised fine-tuning, training on example answers) traces that solve problems in different ways raised OLMo3-7B's pass@8 by 16.9 points on unseen tasks.
  https://arxiv.org/abs/2609.33780

## Ontologies & knowledge graphs for AI

- **CorpusMap gives search agents a map of entities**
  It builds a graph linking entities (people, products, places) to the documents that mention them, so an agent can follow links instead of re-searching, with better answers and fewer tokens.
  https://arxiv.org/abs/2609.37226

## RAG / vector DB tooling

- **AdaTutoRank reranks a whole set of documents at once**
  A reranker (a model that re-orders search results) that picks a complete, non-repetitive set of documents for RAG (feeding docs to an LLM), beating others on ten benchmarks with fewer retrieval calls.
  https://arxiv.org/abs/2609.32472

## Agent orchestration frameworks

- **OpenAI adds computer use to its Agents API**
  The Agents API (hosted agent loop with sandbox and MCP support) can now drive a hosted browser, so your agent can use websites without you running the browser.
  https://openai.com/index/devday-2026-recap/

- **Pydantic AI 2.52.0 fixes a web_fetch security issue**
  Deeply nested attacker HTML could burn CPU and memory in the local `web_fetch` tool, and harness tools like `Shell` and `FileSystem` can now run inside a sandbox.
  https://github.com/pydantic/pydantic-ai/releases/tag/v2.52.0

- **MCP TypeScript SDK 2.2.0 returns full lists by default**
  `listTools()` and similar calls now follow pagination until the end, which changes behaviour if you relied on getting only the first page.
  https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/v2.2.0

## Cloud AI service updates

- **AWS previews Bedrock Managed Agents, powered by OpenAI**
  A hosted agent service on OpenAI's Agents API where each agent gets its own IAM role and CloudTrail logs, free in preview in three US regions beyond the AWS resources you use.
  https://aws.amazon.com/about-aws/whats-new/2026/09/bedrock-managed-agents-preview/

- **Claude models on Bedrock reach India, South Korea and Singapore**
  Claude Opus 5, Sonnet 5 and Haiku 4.5 can now run in these regions, which helps when data must stay in one country.
  https://aws.amazon.com/about-aws/whats-new/2026/09/claude-region-expansion-in-sk/

## AI security & compliance

- **Special chat tokens make prompt injection much stronger**
  Forged chat-template markers work far better when read as real control tokens, and the authors found about 255 of the 400 most-downloaded Hugging Face models still leave tool tokens unprotected.
  https://arxiv.org/abs/2609.35932
