> **Today's big item:** On 16 November, Anthropic said it will give software vendors much less time before it publishes the security bugs it reports to them. The window drops from 90 days to 30 for high and critical bugs, and to 45 days for everything else. Anthropic says AI now finds bugs faster, so someone else is more likely to find the same bug. The new windows apply to reports made from 1 January 2027, so if you maintain software, expect less time to ship patches.

## New model launches

- **Tencent launches Hy4 flash, a cheap 1M-context model**
  A hosted MoE model (many small expert sub-networks, only some used per word) with 12B active parameters, image input and a 1M-token context window (how much text it can read at once) at about $0.07 per million input tokens; Tencent promises open weights but has not released them yet.
  https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/

## New techniques / papers

- **Coding agents still fail when they have to ask colleagues what to build**
  SWE-CoWork drops agents into a simulated company with 26 colleagues across 101 real repos, and the best models passed about 63% of the tests but fully finished fewer than 8% of assignments, so expect trouble when requirements are spread across people and tickets.
  https://arxiv.org/abs/2611.20218

- **Most coding-agent tokens are re-reads of cached context**
  Across nearly one billion tokens from ten weeks of real coding-agent use, 94.8% were reads of cached context (about 260 cached tokens per generated token), and the authors estimate that starting each task with a fresh context would cut energy use by about 60%.
  https://arxiv.org/abs/2611.20873

## Interesting GitHub repos

- **vLLM 0.34.0 changes defaults you may rely on**
  The popular self-hosting inference server now sizes its KV cache (memory that stores past tokens) from the GPU memory that is actually free, uses block size 64 by default, drops Model Runner V1 and adds Mistral Large 4, so read its "Before you upgrade" table first.
  https://github.com/vllm-project/vllm/releases/tag/v0.34.0

## Ontologies & knowledge graphs for AI

- **Power plant assistant: a knowledge graph with fixed plans beat a free-roaming agent**
  At two gas power plants, replacing an LLM agent that planned its own queries with fixed execution plans over a versioned knowledge graph (facts stored as linked entities) cut token use 20x and latency 3x while returning the same results.
  https://arxiv.org/abs/2611.20398

## RAG / vector DB tooling

- **UniGraph: one index for hybrid dense and sparse search**
  Hybrid search (mixing meaning-based vectors with keyword-based ones) usually queries two indexes and merges the results, while this graph index handles both in one pass and lets each query choose its own keyword-versus-meaning weight without a rebuild.
  https://arxiv.org/abs/2611.20758

- **Switching embedding models always means re-encoding everything**
  Across 27 model pairs, tricks for reusing an old vector index (adapters, re-ranking) only delayed re-encoding the full corpus, and the paper gives rules for planning that cost in a RAG (feeding docs to an LLM) system.
  https://arxiv.org/abs/2611.20702

## AI security & compliance

- **Anthropic cuts its bug disclosure window from 90 to 30 days**
  For high and critical bugs reported from 1 January 2027, Anthropic will publish details after 30 days (45 for other bugs), so vendors who get a report from Anthropic will have much less time to patch.
  https://www.anthropic.com/research/coordinated-vulnerability-disclosure-timelines

- **Security test of LangChain, LangGraph, AutoGen and OpenClaw**
  Twelve attacks based on the OWASP Top 10 for agentic apps, including prompt injection (hidden instructions in input) and memory poisoning, led to unauthorised tool calls, and only explicit authorisation, limited tool access and filesystem containment stopped them.
  https://arxiv.org/abs/2611.21259

- **Deep research agents can be steered without injected instructions**
  An "agenda seeding" attack that only plants a made-up evaluation metric on the web made the attacker's choice the top pick in 16–28% of research-agent reports, while classic prompt injection barely worked.
  https://arxiv.org/abs/2611.20045
