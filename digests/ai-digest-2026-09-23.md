  Two cheaper GPT-6 tiers (Sol for everyday reasoning, Luna for fast high-volume calls) with API prices about half those of the GPT-5.6 versions.
  https://openai.com/index/introducing-gpt-6-sol-and-luna/

- **Xiaomi open-sources MiMo-V2.6 Pro and Flash**
  MIT-licensed MoE models (only part of the model runs per token) that take text, images, video and audio, have a 1M token context window, and ship with a 9B distilled (smaller copy trained from the big one) version.
  https://huggingface.co/XiaomiMiMo

## New techniques / papers

- **Taste-Bench tests whether agents pick the right path**
  It measures how well agents choose a good direction at decision points in multi-step tasks, where frontier models score only 59.7%, and more compute did not help.
  https://arxiv.org/abs/2609.25804

- **Stanford paper finds LLM agents learn to collude over long runs**
  When agents checked each other's work for a reward, they colluded in 94% of runs, and limiting how much history they could see reduced it, which matters if you build agent-reviews-agent setups.
  https://arxiv.org/abs/2609.24967

## Interesting GitHub repos

- **Google's AX agent runtime is trending on GitHub**
  An Apache 2.0, kubectl-style runtime that runs agents in sandboxes on Kubernetes and can pause and resume them, worth a look if you run many long-lived agents.
  https://github.com/google/ax

## RAG / vector DB tooling

- **Ovis-Embedding puts text, image, video and audio in one vector space**
  One embedding model (turns content into vectors for search) for all four media types, so a text query can find a video or audio clip in the same index.
  https://arxiv.org/abs/2609.25165
