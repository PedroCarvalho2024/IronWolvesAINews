## New techniques / papers

- **One wrong agent message can flip a correct answer**
  In multi-agent setups a wrong upstream message changed a correct downstream answer in up to 32% of cases, so filter what agents pass to each other instead of forwarding everything.
  https://arxiv.org/abs/2609.36855

- **Mid-Harness checks each terminal command before running it**
  NVIDIA samples several candidate actions and lets a verifier model pick one, raising pass rate on a terminal benchmark from 50% to 68% without changing the agent or its harness (the code that runs the agent's tools).
  https://arxiv.org/abs/2609.39982

- **Self-training search agents can learn to agree on wrong answers**
  When one model writes questions and another answers them, both drift into shared mistakes, and training each on separate halves of the documents fixed this and added about 8 points of accuracy.
  https://arxiv.org/abs/2609.39102

## AI security & compliance

- **Agent skills open 104 security holes across 11 agents**
  Researchers found that untrusted skill files (add-on instructions and scripts) can reach sensitive actions, and 15 of the holes were fully exploited, so only install skills you trust and limit their permissions.
  https://arxiv.org/abs/2609.39065

- **Approval laundering: coding agents run something other than what you approved**
  The paper lists six ways the approved action and the executed action can differ, and shows that checking only at the tool-call boundary does not catch them all.
  https://arxiv.org/abs/2609.38983
