> **Today's big item:** Mistral released the open weights of Mistral Large 4, a 1-trillion-parameter MoE (only part of the model runs per token) model with about 52B active parameters, aimed at coding and cyber defence. You can download it from Hugging Face and run it yourself with vLLM or SGLang; a quantised (compressed to use less memory) version fits on four Nvidia B200 or B300 GPUs. The licence is a modified MIT that is free for commercial use, except companies selling it as a hosted model service need a separate licence.

## New techniques / papers

- **PCM: agents must attach proof when they tell each other things**
  A protocol where claims like "tests passed" between agents carry signed records from a log the agent can't write to, and it caught all but 10 of 712 false messages that plain A2A (an agent-to-agent protocol) accepted.
  https://arxiv.org/abs/2610.39109

## Ontologies & knowledge graphs for AI

- **TCC-RAG: answer time-based questions by following cause-and-effect chains in a knowledge graph**
  It turns a temporal knowledge graph (facts with dates attached) into a graph of causal links and retrieves only the chain that matters, improving multi-step time reasoning by about 63%.
  https://arxiv.org/abs/2610.38366

## RAG / vector DB tooling

- **Glance: let the answering model also rerank the documents**
  Instead of running a separate reranker (a model that re-sorts search results), a small add-on to the 9B generator scores passages from its own cache and beat bge-reranker-v2-m3 on two test sets.
  https://arxiv.org/abs/2610.40454

- **Train embedding models on their own retrieval mistakes**
  For multi-hop RAG (answers that need several documents), training the retriever on the wrong passages it actually picks helps it recover and find all the evidence more often.
  https://arxiv.org/abs/2610.40409

## AI security & compliance

- **Role spoofing: fake "user" text inside tool output can fool models**
  A webpage that copies the format and style of a user message can make the model treat it as a real user instruction, and the authors show a probe (small classifier on model internals) that detects this.
  https://arxiv.org/abs/2610.40396

- **Agents trust README files more than code files**
  The same injected instruction was followed 2.6 times more often by a GPT-5.4 agent when placed in a README or TODO file than in a code or data file, so treat docs in repos as untrusted input too.
  https://arxiv.org/abs/2610.38867

- **SEAL: cleans tool output before a local agent reads it**
  A learned filter removes injected instructions from tool results, cutting attack success on AgentDojo from 34.6% to 0.1% while using about 127x fewer extra tokens than a leading defence.
  https://arxiv.org/abs/2610.39758
