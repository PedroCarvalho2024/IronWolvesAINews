> **Today's big item:** A new study tested 15 prompt-injection detectors, including Meta's Prompt Guard 2, on real agent tool outputs. A detector that topped one benchmark caught only 2% of the attacks in another, at a 1% false-alarm rate. If you rely on a detector, test it on your own agent's tool outputs before you trust its scores.

## New techniques / papers

- **VERSE lets an optimizer test its own edits to an agent's harness**
  The optimizer improves the harness (the code, prompts and tools around the model) by running and replaying its changes before keeping them, reaching 42.3% on held-out tasks against 39.2% for the best baseline.
  https://arxiv.org/abs/2610.02616

- **GraphMemory keeps agent memory small by storing it as a graph**
  Instead of adding every lesson to the prompt, it stores strategies as a graph and pulls only the relevant part per question, using about 81 to 85% fewer tokens to build memory with similar results.
  https://arxiv.org/abs/2610.02687

## Ontologies & knowledge graphs for AI

- **PrivDev maps code-scanner data types to a GDPR privacy vocabulary**
  It links 122 data types found by the Bearer code scanner to the Data Privacy Vocabulary (a standard list of personal-data categories) as an RDF knowledge graph, helpful if you need to show which personal data your code handles.
  https://arxiv.org/abs/2610.03518

## RAG / vector DB tooling

- **Fine-tuning vs RAG for teaching agents how an environment works**
  Fine-tuning won in 15 of 20 settings while RAG (feeding docs to an LLM) needed less data, and a mix of both did best because the retriever often pulled weak examples.
  https://arxiv.org/abs/2610.02542

## AI security & compliance

- **Prompt-injection detectors do much worse outside their own benchmark**
  Across 15 detectors, rankings did not carry over between benchmarks, and the best one on agent tasks was the one trained on agent-style inputs.
  https://arxiv.org/abs/2610.03448

- **Small edits to a GraphRAG index can poison many answers**
  Changing just 0.016% of the summary structures that GraphRAG (RAG over a knowledge graph) builds hijacked 88 to 94% of target questions and got past common defences over 99% of the time.
  https://arxiv.org/abs/2610.02373

- **MIRROR checks messages between agents for tampering**
  It sends each message along several routes and compares hashes, stopping man-in-the-middle edits between agents at a fraction of the cost of using an LLM judge.
  https://arxiv.org/abs/2610.02349
