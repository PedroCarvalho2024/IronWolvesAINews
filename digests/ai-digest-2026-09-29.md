AI digest for 2026-09-29 — 5 items

> **Today's big item:** Agent tooling dominates today. Hindsight, an open-source "memory for agents" project, is the top trending AI repo on GitHub, and a new paper shows how to build agent tests from real usage logs.

## New techniques / papers

- **TraceDance builds agent benchmarks from real deployment traces**
  A system that turns logs of real agent runs into tests (evals, meaning ways to score an agent), useful if you want tests that match real usage instead of toy tasks.
  https://huggingface.co/papers/2609.33295

- **Multi-teacher on-policy distillation with domain normalisation**
  A paper on distillation (training a small model to copy bigger ones) when several teacher models each cover different domains, useful if you fine-tune small models.
  https://huggingface.co/papers/2609.35347

## Interesting GitHub repos

- **Hindsight: agent memory that learns**
  A Python library that gives agents long-term memory across sessions, useful if your agents forget everything between runs.
  https://github.com/vectorize-io/hindsight

- **OpenRig runs Claude Code and Codex together**
  A multi-agent harness (a wrapper that coordinates several coding agents) that treats different coding agents as one system, useful if you want to compare or combine them.
  https://github.com/mvschwarz/openrig

- **Paperclip: an app to manage agents at work**
  An open-source TypeScript app for managing and supervising a team of agents, useful as a reference for orchestration UIs.
  https://github.com/paperclipai/paperclip
