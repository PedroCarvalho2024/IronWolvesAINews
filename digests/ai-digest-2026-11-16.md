> **Today's big item:** Alibaba made Qwen4-Max generally available on 16 November, after a five-day preview that was limited to its Token Plan. It is a closed-weights MoE (many small expert sub-networks, only some used per word) with 2.4 trillion parameters, native image input and a 1-million-token context window, now callable through the QwenCloud API. Alibaba says it cuts average cost per task by about 60% versus Qwen3.8-Max on its own benchmark, and that smaller open-weight Qwen4 models will follow, with no date given.

## New techniques / papers

- **More agents usually do not beat one model with the same budget**
  A review of 516 multi-agent setups from nine studies found they matched or lost to a single model given the same compute in 74% of fair comparisons, so only split work across agents when each agent sees different evidence or checks results against something external.
  https://arxiv.org/abs/2611.17610

- **CarryOn: learning what a long-running agent should keep in context**
  A context manager that keeps a short task state plus linked evidence and picks what to keep without extra LLM calls, reaching 75.7% task success on AppWorld, OfficeBench and Tau2 Telecom, 6.7 points above the best baseline.
  https://arxiv.org/abs/2611.17808

- **MEM-SQL: text-to-SQL that reuses past queries**
  By storing templates, reusable SQL blocks and maps from business terms to table columns, this text-to-SQL method (turning questions into database queries) raised accuracy from 37.1% to 50.0% across six models while using 76.6% fewer input tokens.
  https://arxiv.org/abs/2611.18338

## AI security & compliance

- **LinEra: really deleting things from an agent's memory**
  Agent memory (notes an agent saves between sessions) often copies facts into summaries, and this scheme encrypts each memory with keys tied to its sources so that deleting one source makes every derived copy unreadable, which matters for GDPR "right to be forgotten" requests.
  https://arxiv.org/abs/2611.18133

- **Agents break rules buried in documents far more than rules you tell them**
  In 97 workplace scenarios, persistent agents broke a rule written in an internal document 43.6% of the time versus 8.5% when the user stated the same rule, so put hard limits in the prompt or in code, not only in docs the agent reads.
  https://arxiv.org/abs/2611.17460
