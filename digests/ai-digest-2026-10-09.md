> **Today's big item:** At Gemini at Work 2026, Google launched the Gemini agent, a single "universal" work agent that you reach through one API, the CLI, Workspace, Microsoft 365 or Slack. It spins up temporary sub-agents for parallel steps, keeps running for hours after you close the client, and connects to any MCP server (a standard way to plug tools into agents). It can also route each task to Gemini or Claude models to balance quality and cost.

## New techniques / papers

- **Tool-using agents miss failures that look like normal output**
  Agents spotted 91% of explicit tool errors but only 59% of plausible wrong values, and telling them to "check each result" did not help, so validate tool output in code.
  https://arxiv.org/abs/2610.10062

- **Knowing the agent topology helps diagnose multi-agent failures**
  MAScope works out who talks to whom (the topology) from execution traces and gives that to an LLM judge, which roughly doubled diagnosis accuracy for a small model at about 6% of the cost of a large one.
  https://arxiv.org/abs/2610.10126

## Cloud AI service updates

- **Google launches the Gemini agent for work**
  One agent and one API with sub-agents, MCP tools, shared skills, four kinds of memory, per-agent identities and spend caps, worth a look if you build internal agents on Google Cloud.
  https://cloud.google.com/blog/products/ai-machine-learning/welcome-to-gemini-at-work-2026

- **OpenAI adds an Ultrafast tier for GPT-6.1 Sol in the API**
  Set `service_tier="ultrafast"` to get up to 8x faster responses at $12 / $60 per million input / output tokens, useful for agent loops that make many quick tool calls.
  https://developers.openai.com/api/docs/guides/ultrafast-mode
