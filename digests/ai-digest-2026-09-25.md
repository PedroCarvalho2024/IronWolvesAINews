## New techniques / papers

- **IterSynth splits planning and writing in deep search agents**
  A deep search agent (an LLM that runs many web searches to answer one question) where one role plans searches and another writes the answer, and its 8B model beats similar-sized agents by 4.2%.
  https://arxiv.org/abs/2609.29444

- **Agent-Editing World Model predicts if an agent's step actually helps**
  Instead of guessing what a tool will return, AEWM judges whether each agent action moves the task forward, which added 3.2 to 6.7 points across six agent benchmarks.
  https://arxiv.org/abs/2609.28416

## Agent orchestration frameworks

- **Claude Tag can now use your personal connectors in Slack channels**

## Cloud AI service updates
